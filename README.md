# 말해보카 소개 슬라이드

말해보카를 위한 자기소개 슬라이드 페이지입니다.

## 파일 구조

- `index.html` - 메인 HTML 파일

## 실행 방법

로컬 서버로 실행:

```bash
cd /Users/quokka/malheboka-intro
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속하세요.

## 특징

- 반응형 디자인
- Font Awesome 아이콘 사용
- Pretendard 폰트 적용
- 카드 호버 효과
- 그라데이션 배경
